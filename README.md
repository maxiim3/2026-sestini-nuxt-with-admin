# Sestini Pizza — 2026

Site de [Sestini Pizza](https://www.sestini-pizza.fr), camion pizza au feu de
bois près de Montpellier. Nuxt 4, administration pilotable par IA (MCP), PWA.

- Cahier des charges : [`docs/CDC.md`](docs/CDC.md)
- Guide pour les agents : [`AGENTS.md`](AGENTS.md)

## Démarrer

```bash
pnpm install
pnpm dev
```

Le site tourne sur http://localhost:3000.
